* Attachment names

An attachment id is a single filename inside the attachment store. Adjacent dots inside that filename are valid, so files such as =report..txt= remain downloadable and retain their display names. Previously stored ids use the same rule. Leading dots, path separators, empty ids and parent-directory traversal remain rejected.

=tests/test-attachment.c= stores files with adjacent and leading dots in their original names, resolves the generated ids, reads back their bytes and checks the displayed names. The hostile-id tests continue to enforce the store boundary.
