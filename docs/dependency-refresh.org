* Fixes required by validation

The initial clean build exposed libreclaw GIR warnings: duplicate gtk-doc blocks, unresolved external namespaces, missing ownership annotations, and unregistered result records. Existing local introspection fixes from libreclaw =24055e9=, podomation =1b8df7d=, and mcp-glib =aaba1fd= were applied to current master and validated with their ownership and metadata regression tests. The scanner now rejects warnings rather than silently emitting incomplete bindings. Clawtilla searches libreclaw's build directory for the bundled namespaces, as in the existing local integration fix =3292689=.

The htmx-glib element and upload tests used =g_unlink()= without including =glib/gstdio.h=. Adding that header removes the implicit-declaration warnings without weakening compiler diagnostics.

* Validation

All 15 recursive dependency checkouts passed their =make -j8 test= suites, including repeated copies. After the fixes, =make -j8 clean-all all= completed without compiler or GIR warnings. The affected podomation and libreclaw suites were rerun against the final sources, along with podomation's fresh =check-gir= and mcp-glib's =test-gir= metadata regression.

Clawtilla passed =make -j8 clean tests=, followed by =make -j8 all= and =make -j8 test=. The application suite ran 81 C test binaries and four shell checks. The GTK and web room integration scripts explicitly skipped because =CLAWT_TEST_INTEGRATION=1= was not enabled; live podman, libvirt, gowl, and GUI integration were not exercised. Runtime warnings deliberately triggered by negative test cases are distinct from compiler and GIR diagnostics, which were absent from the final builds.
