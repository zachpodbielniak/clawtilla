* Vendored web assets

| File                 | Upstream                  | Version | License |

| =office.js=          | this repository           | --      | AGPL-3.0-or-later, with the rest of clawtilla |

Checked in rather than fetched at build time, and served by
=clawtilla-web= from its own directory rather than from a CDN.

Three reasons, in order of how much they matter:

1. *A fleet console must work without the public internet.*  The whole
   point of binding the tailnet address is reaching the fleet from a
   laptop over WireGuard.  A page that then blocks on =unpkg.com= is
   useless in exactly the situation it was built for.

2. *A CDN script drives every agent on the machine.*  This page can
   start, stop, reconfigure and delete agents, and run commands inside
   their computers.  Handing a third party the ability to change what
   runs there, on every page load, is not a dependency -- it is an open
   door.

3. *Reproducibility.*  A build that reaches the network is a build that
   can produce different output tomorrow.

To update one, replace the file, note the new version here, and record
its checksum below.

=office.js= is not vendored: it is clawtilla's own canvas renderer for the Office page (=clients/web/web-office-view.c= serves it its data), kept as a file rather than a C string because it is a program, not a snippet.  It changes with the code, so it has no checksum here, and it is excluded from the command below.  It is served from this directory for the same reasons as the rest, and fetches nothing but this server's own =/office/*.json=.

#+begin_src bash
sha256sum data/web/htmx*.js data/web/icons/*.png
#+end_src

** The app icons

The web app manifest's icons (see =docs/web-client.org=, "Installable,
with no service worker") are the project logo scaled down, made once
and checked in rather than generated at build time, so building the
client needs no image tool.  =data/logo.png= is a 1024-pixel square
whose art sits inside the central circle on a full-bleed background,
which is what a =maskable= icon needs, so the 512 serves as both.  To
remake them after the logo changes (ImageMagick 7):

#+begin_src bash
for size in 180 192 512
do
    magick data/logo.png -resize "${size}x${size}" -strip \
        -define png:exclude-chunks=date,time \
        "PNG24:data/web/icons/clawtilla-${size}.png"
done
#+end_src

then record the new checksums above.  =tests/test-web-render.c= reads
each PNG's header and fails if a size in the manifest does not match the
file.
