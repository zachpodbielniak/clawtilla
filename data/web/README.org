* Vendored web assets

| File                 | Upstream                  | Version | License |
|----------------------+---------------------------+---------+---------|
| =htmx.min.js=        | https://htmx.org          | 2.0.4   | BSD-2   |
| =htmx-ext-sse.js=    | htmx-ext-sse              | 2.2.3   | BSD-2   |

Checked in rather than fetched at build time, and served by
=clawtilla-web= from its own directory rather than from a CDN.

Three reasons, in order of how much they matter:

1. *A fleet console must work without the public internet.*  The whole
   point of binding the tailnet address is reaching the fleet from a
   laptop over WireGuard.  A page that then blocks on =unpkg.com= is
   useless in exactly the situation it was built for.

2. *A CDN script drives every agent on the machine.*  This page can
   start, stop, reconfigure and delete agents, and run commands inside
   their computers.  Handing a third party the ability to change what
   runs there, on every page load, is not a dependency -- it is an open
   door.

3. *Reproducibility.*  A build that reaches the network is a build that
   can produce different output tomorrow.

To update one, replace the file, note the new version here, and record
its checksum below.

#+begin_src bash
sha256sum data/web/*.js
#+end_src
